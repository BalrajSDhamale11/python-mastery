## 📌 What This Is

This repo contains code written while working through a structured Python learning curriculum, organized phase by phase. Each folder corresponds to a phase and sub-unit of the curriculum, containing the exercises and practice code completed for that unit.

## 🗂️ How It's Organized

The repo mirrors the curriculum structure:

| Element | Meaning |
|---|---|
| `phase-XX-<name>/` | One curriculum phase |
| `<unit-number>-<topic>/` | A specific learning unit inside a phase |
| `projects/` | Larger, multi-concept builds (added later) |
